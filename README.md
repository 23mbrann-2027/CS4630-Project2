## File Execution

### Phase 1
1. Create a folder labeled `Data`.

2. Download the UCI HIGGS dataset from either the source or the google drive link provided above. Leaving it in it's compressed "csv.gz" format, move the file into the `Data` folder.
    - Make sure to leave the name as `HIGGS.csv.gz`

3. Download required packages

### Phase 2
1. To run all required tasks for this project, simply run the `KMeans.py` file. You can do this by typing following in terminal: python KMeans.py
